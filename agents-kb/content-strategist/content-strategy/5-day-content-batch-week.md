# The 5-Day Content Batch Week: Research → Ideation → Scripting → Filming → Editing

**Source**: https://www.instagram.com/reel/DdCZ6_YvTzG/
**Category**: content-strategy
**Added**: 2026-09-14

## Core Insight
A full month of content gets produced in one structured work week by assigning one production stage to each weekday, research on Monday, script ideation on Tuesday, scripting+captions on Wednesday, batch filming on Thursday, editing on Friday, instead of trying to plan/write/film/edit each post one at a time.

## How It Works
- **Monday, Research**: pick 5-7 niche keywords, search each in IG Explorer under the Reels tab, and save every video with 1M+ views. Aim for 50-100 saved videos total. Optional: log each saved video's hook + topic into a spreadsheet for reference.
- **Tuesday, Ideation**: every script gets planned in 4 sections before writing:
  1. **Hook**, pick a proven viral hook from the research and adapt it across 3 forms: verbal (spoken line), written (on-screen text), visual (the opening shot/image)
  2. **Value**, using your own knowledge, decide the step-by-step teaching content of the video
  3. **CTA**, pick a template from a CTA-options chart
  4. **Format**, pick a delivery style from a format-options chart: Voiceover, Talking Back & Forth, Reaction, Setting Changes, Whiteboard, Shot/Angle Change, Multitasking, Visual, Green Screen, Clone
  - Pick a posting schedule first, it determines how many ideations to produce this round.
- **Wednesday, Scripting & Captions**: turn each ideation into a full script + shot list, then write the caption for each using a fixed caption template.
- **Thursday, Filming**: batch-film every video for the month in one sitting (shown filming 30 videos back to back, using outfit/setting changes to signal separate videos without separate shoot days).
- **Friday, Editing**: get everything edited (yourself or a hired editor) so the whole batch is ready to post.

## Example
Hook example shown on screen: Verbal, "If I Woke Up 30 Pounds Overweight, Here is How I Would Lose it in 90 Days"; Written, "How to go from 30% to 15% Bodyfat in 90 Days"; Visual, before/after image. Value: step-by-step 90-day fat-loss plan (calorie deficit + lifting 4x/week).

## When to Use
When content planning is happening reactively, one post at a time, and it's eating time all week. Run this as one dedicated production week (or sprint) per month instead: a fixed day per stage turns "what do I post today" into a pipeline with a fixed weekly rhythm.
