# Create a Branded Slide Deck in 60 Seconds (Claude Design)

**Source**: https://www.instagram.com/reel/DeUyS0JoIVI/
**Category**: content-strategy
**Added**: 2026-10-11

## Core Insight
Use Anthropic's Claude Design tool to turn a script into a fully branded slide deck (the kind used in "slide deck" style Reels and carousels) in about a minute, instead of building it by hand in Canva or Figma.

## How It Works
- Open Claude Design, pick "Slide deck" under New Prototype, name the project.
- Start with context: paste a prewritten prompt that includes the design system, a screenshot or two of other slide decks/carousels with your branding, and a dragged-in Figma file if you have one.
- Paste the actual script/content the deck is for (not just a vague brief) along with the prompt, and fill in any blanks before sending.
- Send it, let the AI generate a full slideshow draft from the context + script.
- Before committing, ask for 2-3 versions with different visual approaches to compare.
- From there, either manually edit individual slides (colors, text, layout) or leave comments and have the AI revise the slides directly, including restructuring slide order/content via chat.

## Example
Creator (@personalbrandlaunch) showed building a "TOFU/MOFU/BOFU funnel content" slide deck: pasted a funnel-content script, got a neon green branded deck generated with a recurring funnel diagram that progressively highlights TOFU → MOFU → BOFU across slides, then asked for 2-3 version options and tweaked colors/background directly in the editor.

## When to Use
Any time you need a branded, on-visual-identity slide deck or carousel fast (TOFU/MOFU/BOFU explainers, tutorial decks, "how it works" visuals) without doing manual design work slide-by-slide.
