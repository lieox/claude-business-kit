# Reels vs. Carousels vs. Stories - Format Cheat Sheet

## Core Insight
Each format serves a different purpose in the funnel, Reels grow audience, Carousels drive engagement, Stories convert to leads.

## How It Works
- **Reels**, shown to non-followers + some current followers → goal: get new followers → post educational/storytelling content → 4-7x/week → permanent
- **Carousels**, shown to current followers + some non-followers → goal: get engagement → post educational, storytelling, social proof → 1-3x/week → permanent
- **Stories**, shown to current followers only → goal: get leads → post social proof content → 5-7x/week → 24-hour lifespan
- **Single images** - goal: share personal updates (keeps you human between bigger posts)
- **Go Live** - goal: deepen personal connection / nurture with your most engaged followers

## Proof From the Creator's Own Insights (carousel version)
- **Who sees it** (views split): Reels 829,261 views, 70.7% non-followers / 29.3% followers · Carousels 37,546 views, 91.8% followers / 8.2% non-followers · Stories 13,746 views, 97.5% followers / 2.5% non-followers.
- **What each one produced**: Reels → 76,987 follows · Carousels → 609,456 interactions (191,109 likes, 304,341 saves, 101,090 shares, 12,916 comments) · Stories → 123 link clicks.
- **What to post on each** (sharper than the list above): Reels = educational + storytelling · Carousels = educational + client results · Stories = client results *only*.
- **Frequency**: Reels 4-7x/week · Carousels 1-2x/week (narrower than the 1-3x in the reel version) · Stories 5-7x/week.
- **Sample week (her Google Calendar)**: Reels at 9:00 AM on most days, Carousels at 10:30 AM on Tuesday and Thursday, Stories daily at 3 PM. The calendar's summary panel reads Reels 6, Carousels 2, Stories 6.

## Example
Use Reels to build audience, Carousels to deepen trust and engagement with existing followers, Stories to convert warm followers into leads or clients.

The carousel version practices what it preaches: its closing slide is pure client results, four before/after profile screenshots (34 → 474K followers, 4,149 → 106K, 208 → 87.6K, 0 → 17.3K), followed by a comment-keyword CTA ("Comment SMM").

## When to Use
When planning your weekly content mix, use this as a format allocation framework to ensure each piece of content serves a specific funnel goal.
