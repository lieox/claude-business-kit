# Clone Any Website With a Claude/Codex Skill, Then Rebrand It

**Source**: https://www.tiktok.com/@nomadatoast/video/7650898405190798625
**Category**: playbooks
**Added**: 2026-06-18

## Core Insight
A Claude/Codex skill can fully clone even the most complex website from any live link, pixel-faithful, so you can lift a specific animation, UI section, or 3D element from a reference site and adapt it to your own brand instead of rebuilding it from scratch.

## How It Works
- Point the skill at any active URL (the reference site you admire).
- It reproduces the full site faithfully: layout, scroll animations, interactive 3D elements, galleries, contact section, etc.
- You then swap in your own content and identity (text, assets, colors, name) to rebrand the clone as yours.
- Output is a deployable site (the demo was running on a vercel.app preview).

## Example
The creator clones a polished agency/product reference (Anima-style work page, a hardware/glasses product page, an NFT-style "playground" gallery grid, scroll-driven 3D, a bold Contact page) and rebrands the whole thing to the "NomadaToast / toast" identity, keeping the animations and 3D but replacing every asset and message with his own.

## When to Use
When a client points at a site and says "make mine like that," or when you want to reuse a proven animation / 3D section / layout. Clone the reference with the skill, then adapt it to the brand, rather than reverse-engineering the effect by hand. Pairs with [[standalone-html-first-then-convert]] when the clone later needs to become an Elementor build.
