# איפה שומרים קבצים

תיקיית העבודה הראשית מוגדרת ב-CLAUDE.md, תחת "איפה דברים נמצאים".

- **כל תוצר נכנס לתיקיית העבודה**, למקום שלו: תיקיית הפרויקט או תיקיית הלקוח. לא על שולחן העבודה, ולא בתיקייה חדשה ליד תיקיית העבודה.
- **גיבויים** נכנסים ל-`.backups/<נושא>-<תאריך>/` בתוך תיקיית העבודה, והתיקייה הזו נמצאת ב-`.gitignore`.
- **קודם בודקים את git.** קובץ שכבר נמצא ב-git לא צריך גיבוי, כי ההיסטוריה של git היא הגיבוי.
- **קבצים זמניים** (תוצאות ביניים, ניסיונות, הורדות) נכנסים לתיקייה זמנית ולא לתוך הפרויקט.
- **קובץ שהורד מהאינטרנט** נכנס לתיקייה ריקה משלו, ולא מריצים ממנו קוד בלי לקרוא אותו קודם.
- **מעדיפים לערוך קובץ קיים** על פני יצירה של קובץ חדש שעושה כמעט אותו דבר.
- **שינוי בהרבה קבצים בבת אחת:** קודם מציגים את הרשימה המלאה של מה שישתנה, ומחכים לאישור.

## שתי מלכודות של גיבוי
- גיבוי שנעשה לפני שמחקו סוד מקובץ שומר את הסוד. אחרי ניקוי של סוד, מוחקים גם את הגיבויים מלפניו.
- גיבוי של מידע לקוח שהתחייבתם למחוק הוא עוד עותק שצריך למחוק.
