# תבנית לפרויקט חדש

כל פרויקט ב-`projects/` נבנה באותו מבנה, כדי שקלוד (וכל אחד אחר) ימצא בו דברים בלי לשאול.

```
projects/
└── שם-הפרויקט/
    ├── README.md      חובה: מה זה, איך מריצים, מה המצב
    ├── CLAUDE.md      חובה: מה קלוד צריך לדעת כשהוא עובד על הפרויקט
    ├── docs/          מסמכים: קובץ לכל נושא
    └── agents/        רק אם לפרויקט יש סוכנים משלו
```

## README.md
- מה הפרויקט עושה, במשפט או שניים.
- איך מתקינים ומריצים.
- הכלים והשירותים שהוא תלוי בהם.
- המצב היום ומה הצעד הבא, עם תאריך.

## CLAUDE.md
- ההקשר שקלוד צריך: למי זה, מה המטרה, מה אסור לשבור.
- החלטות חשובות והסיבה שלהן.
- בעיות ידועות ומגבלות.

## docs/
- קובץ אחד לכל נושא (`decisions.md`, `setup.md`, `api.md`), לא מסמך אחד ענק.

## לקוח חדש
אותו רעיון, בתיקיית הלקוחות: `<שם הלקוח>.md` עם מי הלקוח, מה השירות, אנשי קשר ומה הובטח מול מה בוצע, ותיקיית `לשליחה/` למה שיוצא ללקוח.
