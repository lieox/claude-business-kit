# איך בונים את סביבת העבודה של Claude Code

הסביבה של Claude Code (ההגדרות, הסוכנים, הסקילים, ההוקים והזיכרון) נקראת "הארנס". המסמך הזה מתאר מבנה שעובד לאורך זמן, על בסיס סביבה שרצה כמה חודשים עם עשרות סוכנים. אפשר להעתיק אותו כמו שהוא, או לקחת רק חלקים.

## שני רעיונות שכל השאר נשען עליהם

**1. מקור אמת אחד, מגובה ב-git.** כל ההגדרות של קלוד יושבות ב-`~/.claude/`. בתוך תיקיית העבודה, שהיא ריפו של git, יוצרים קישור בשם `claude-global` שמצביע ל-`~/.claude/`. ככה ההגדרות, הסוכנים והסקילים נכנסים לאותו גיבוי כמו כל העבודה, בלי להעתיק קבצים פעמיים.

**2. כל סוכן חי בתוך הפרויקט שלו.** הקובץ של הסוכן לא יושב ישירות ב-`~/.claude/agents/`. הוא יושב ב-`projects/<שם>/agents/<שם>.md`, ליד מאגר הידע והזיכרון שלו. קישור ב-`~/.claude/agents/` חושף אותו לכל הסשנים. כל סוכן הוא יחידה אחת שאפשר לגבות, לשפר או למחוק בנפרד.

## העץ

```
תיקיית-עבודה/                      ריפו של git
├── claude-global  ──►  ~/.claude/   קישור: ההגדרות נכנסות לגיבוי
├── projects/
│   ├── <סוכן>/
│   │   ├── agents/<סוכן>.md        ההגדרה (נחשפת דרך קישור)
│   │   ├── commands/               פקודות / של הסוכן
│   │   └── knowledge/
│   │       ├── index.md            אינדקס: שורה לכל קובץ
│   │       ├── memory.md           מה הסוכן למד תוך כדי עבודה
│   │       └── <נושא>/<קובץ>.md    קובץ אחד לכל תובנה
│   └── <פרויקט לקוח>/
├── knowledge/                      ידע משותף: לקוחות, תבניות, מערכות עיצוב
└── tools/                          סקריפטים שההוקים והמשימות המתוזמנות מריצים

~/.claude/
├── CLAUDE.md                       החוקים שחלים על כל שיחה
├── settings.json                   הרשאות, הוקים, תוספים
├── agents/                         קישורים לסוכנים שבפרויקטים
├── commands/                       קישורים לפקודות
├── skills/                         סקילים
└── hooks/                          הסקריפטים של ההוקים
```

## הזיכרון

כל עובדה נשמרת בקובץ קטן משלה. למשל, "הלקוח מעדיף מייל ולא ווטסאפ" הוא קובץ עם כותרת ותיאור בשורה אחת.

קובץ `MEMORY.md` מחזיק שורה אחת לכל זיכרון, וקלוד טוען אותו בכל שיחה. הוא קורא את האינדקס ופותח רק את מה שרלוונטי למה שביקשתם.

כשקובץ זיכרון מתחיל להיראות כמו יומן של כל מה שקרה, תוציאו ממנו את ההיסטוריה ותשאירו רק את מה שנכון היום.

גם לכל סוכן יש `memory.md` משלו. הוא קורא אותו בתחילת משימה, ומוסיף שורה כשלמד משהו שיחזור.

## ההוקים שמחברים את הסשן לעולם

| מתי | מה רץ | למה |
|---|---|---|
| תחילת סשן | טעינת הזיכרון והמשימות הפתוחות, סנכרון git | כל שיחה מתחילה עם ההקשר המלא |
| לפני פקודה | חסימת מחיקות ופקודות מסוכנות, הגנה על קבצי סודות | טעות אחת לא מוחקת עבודה |
| אחרי תשובה | בדיקת שפה, רישום לסוכן ראש המטה, התראה | הסשן מזין את הלמידה של המחר |
| כשקלוד מחכה | התראה במחשב | לא מפספסים שאלה שלו |

ארבעה הוקים כאלה כבר מוכנים בתיקייה `claude-config/hooks/`.

## משימות מתוזמנות, מחוץ לקלוד

דברים שצריכים לקרות גם כשאף אחד לא פותח שיחה: תדריך בוקר, בדיקת קמפיינים יומית, גיבוי לגיט בבוקר ובערב. ב-Windows זה Task Scheduler, ובמק `launchd`. כל משימה מריצה `claude -p "<פקודה>"` או סקריפט, ושומרת את הפלט לקובץ או שולחת אותו לטלגרם.

## להקים מאפס

**במק:**
```bash
mkdir -p ~/work/claude && cd ~/work/claude && git init
ln -s ~/.claude claude-global

mkdir -p projects/myagent/agents projects/myagent/knowledge
# כותבים את projects/myagent/agents/myagent.md, ואז חושפים אותו:
ln -s "$PWD/projects/myagent/agents/myagent.md" ~/.claude/agents/myagent.md
```

**ב-Windows** (Command Prompt):
```
mkdir %USERPROFILE%\work\claude && cd %USERPROFILE%\work\claude && git init
mklink /J claude-global "%USERPROFILE%\.claude"
```
`mklink /J` יוצר קישור לתיקייה בלי הרשאות מנהל. קישור לקובץ בודד (`mklink` בלי `/J`) דורש הרשאות מנהל או "מצב מפתח" (Developer Mode) מופעל ב-Windows. אם אין אחד מהם, מעתיקים את קובץ הסוכן ל-`%USERPROFILE%\.claude\agents\` ומעדכנים אותו ידנית.

## מה לא להכניס לגיט
טוקנים, מפתחות, קבצי `.env`, הגדרות בוטים עם טוקנים (`bots.json`, `mcp.json`) ומידע של לקוחות שהתחייבתם למחוק. כל אלה נכנסים ל-`.gitignore` לפני הקומיט הראשון.
